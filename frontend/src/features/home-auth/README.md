# Home & Auth Feature

Landing hero experience, customer/vendor registration & login modals, profile management, and terms of service.

## Contents
- `HomePage.jsx`: Main public landing page with interactive event exploration.
- `AuthModal.jsx`: Modal interface supporting customer login/signup and vendor onboarding.
- `TermsModal.jsx`: Platform policies, privacy commitments, and terms dialog.
- `DetailsPage.jsx`: User profile and security settings view.
- `authService.js`: Customer and vendor authentication engine with SHA-256 password hashing.
- `authService.test.js`: Unit tests verifying account login and credentials.
- `home-auth.css`: Styles for hero section, event cards, auth modals, and account details.
